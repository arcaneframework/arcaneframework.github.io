Detailed Description

Minimal hierarchical property tree with string leaf values.

This class replaces the previous use of 'boost::property_tree::ptree'. It only implements the subset of the Boost API that is needed by Alina: path-based access using '.' as separator, insertion-ordered children and string values for leaves. A subtree is itself a 'PropertyTreeImpl' (like the Boost class), so a 'PropertyTree' can alias any node of the tree.
