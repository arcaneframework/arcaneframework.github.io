Detailed Description

template<class BaseIterator>
class Arcane::Alina::adapter::permutation_iterator< BaseIterator >

Random-access iterator over a sequence viewed through a permutation.

The element at offset i of the underlying sequence base is base[perm[i]], where perm is a pointer to a permutation table of ptrdiff_t. This is an internal replacement for 'boost::permutation_iterator'.
