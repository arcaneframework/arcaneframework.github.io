Detailed Description

template<typename ItemType_, typename VectorAccessor_, typename Extents>
class Arcane::Accelerator::MeshVectorMDVariableViewBase< ItemType_, VectorAccessor_, Extents >

Base class for views of multi-dimensional vector variable over a mesh item.

MatrixAccessor_ has to be NumVectorxDataViewGetter or NumVectorDataViewGetterSetter
