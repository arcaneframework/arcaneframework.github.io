Detailed Description

A variable all-to-all of Int64.

The send buffer is grouped by destination. In one round the exchange is posted non-blocking when the parallel manager offers it, so that the caller can work until wait(); in several rounds it is done at once. The send buffer must stay alive until wait().

Int32 nb_rank )
staticprivate

g_max is the largest number of Int64 any rank sends or receives over the whole exchange. A round sends at most ceil(count / nb_round) to each rank, so at most g_max / nb_round + nb_rank in all.
