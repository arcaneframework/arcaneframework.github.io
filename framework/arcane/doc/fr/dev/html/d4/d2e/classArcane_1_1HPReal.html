Description détaillée

Classe implémentant un nombre réel de haute précision.

Cette classe est basée sur l'article :

Obtaining identical results with double precision global accuracy on different numbers of processors in parallel particle Monte Carlo simulations (Mathew A. Cleveland, Thomas A. Brunner, Nicholas A. Gentile, jeffrey A. Keasler) in Journal Of Computational Physics 251 (2013) 223-236.

Les opérations possibles sont l'accumulation (opérateur+=()), la réduction (reduce()) et la conversion en Real (toReal()). D'autres opérations telles que la division ou la multiplication ne sont pas possibles.

Pour être conforme au type 'Real' classique, le constructeur par défaut de cette classe n'effectue aucune initialisation.

La méthode toReal() permet de convertir le HPReal en un Real classique. L'utilisation typique est la suivante :

HPReal r(0.0);
ArrayView<Real> x = ...;
for( Integer i=0, n=x.size(); i<n; ++i ){
// Accumule la valeur
r += x[i];
}
Real final_r = r.toReal();

Évolution 12/18/18 :

Correction de l'erreur de l'algorithme de base pour HPReal statique _doTwoSum(Real a, Real b)

Real sum_error = (a - (value-approx_b) + (b-approx_b));

est devenu (conformément à la Ref 1)

Real sum_error = (a - (value-approx_b)) + (b-approx_b);

Correction de l'erreur dans HPReal statique _doQuickTwoSum(Real a,Real b)

il est nécessaire de tester si a>b et d'inverser a et b si ce n'est pas le cas (voir Ref 2, 3, 4)

Modification de Accumulate et Reduce, Accumulate et Reduce étaient basés sur la Ref 1, qui est basée sur la Ref 4

Ajout des produits tels que proposés dans la Ref 2 (conformément à la Ref 5) de HPReal*Real ou HPReal*HPReal (nous prenons la même valeur de p pour la fonction SPLIT() que dans la Ref 2, 4, 5)

Notez que le produit Real*Real dans la Ref 4 (p.4) n'est pas écrit de la même manière que ceux dans la Ref 2 (p.2) ou 5 (p.3)

+++++++++++++++++

Globalement, les algorithmes de réduction ou les erreurs accumulées uniquement par addition sont moins bons

L'algorithme 6 de DD_TWOSUM [Ref 2] est également moins bon :

static HPReal accumulate(Real a,MYHPReal b)
{
HPReal x(_doTwoSum(a,b.value()));
Real d= x.correction() + b.correction();
HPReal u(_doQuickTwoSum(x.value(),d));
return _doQuickTwoSum(u.value(),u.correction());
}

ou

HPReal reduce(HPReal a,HPReal b)
{
HPReal x(_doTwoSum(a.value(),b.value()));
HPReal y(_doTwoSum(a.correction(),b.correction()));
Real d= x.correction() + y.value();
HPReal u(_doQuickTwoSum(x.value(),d));
Real w=y.correction()+u.correction();
return _doQuickTwoSum(u.value(),w);
}
