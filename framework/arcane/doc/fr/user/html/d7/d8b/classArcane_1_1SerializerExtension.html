Description détaillée

Classe qui étend les fonctionnalités de l'ISerializer.

Cette classe vous permet de sérialiser des tableaux multidimensionnels ou des tableaux de chaînes de caractères. Elle utilise les méthodes de l'ISerializer classique. Vous pouvez détruire cette classe entre les étapes de sérialisation, elle ne stocke aucune donnée.
